HOW IT WORKS

가입은 1분,

01

테슬라 계정 연결

공식 OAuth 한 번이면 끝. 개발자 계정도, API 요금도 없습니다. Fleet API 비용은 teslam.io가 전부 부담합니다.

02

평소처럼 달린다

주행 중에만, 60초마다 신호 4개가 조용히 쌓입니다. 출퇴근이든 강릉 번개든, 달린 만큼이 전부입니다.

03

DRV로 돌아온다

1 km = 10 DRV. 쌓인 DRV는 수퍼차저 크레딧 같은 실물로 바뀝니다. 점수판이 곧 지갑입니다.
